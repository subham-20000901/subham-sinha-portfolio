# Subham Sinha — Portfolio

Modern interactive portfolio built with Next.js, TypeScript, Tailwind CSS, Framer Motion and Lucide React.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Customize

Update `data/portfolio.ts` for profile, skills, experience, projects and education. Replace the files in `public/` when you want to change the profile image or resume.

Before deploying, replace the placeholder GitHub/LinkedIn URLs and project demo/repository links in `data/portfolio.ts`.
